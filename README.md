# Password_strength_checker-using-Python-
An interactive command-line Python tool that checks password strength, estimates crack time, and provides security feedback using the zxcvbn library.


🔐 Password Strength Checker (Python)

A command-line based Password Strength Checker built using Python and the zxcvbn library.
This tool analyzes passwords using real-world attack patterns and provides an accurate strength score, crack time estimation, and security feedback.

📌 Features

Interactive input-based password checking

Strength score from 0 (Weak) to 4 (Strong)

Estimated password crack time

Actionable feedback and suggestions

Real-world password analysis using zxcvbn

Simple, beginner-friendly Python code

🛠 Technologies Used:

-Python 3
-zxcvbn (Password Strength Estimation Library)

⚙️ Installation:

1️⃣ Install Python

-Make sure Python 3.x is installed on your system.

Check version:

-python --version

2️⃣ Install Required Library
-pip install zxcvbn

▶️ How to Run
-python check_password_strength.py
